### 关键改动：右上角「收藏」→「设置」

按需求，网页浏览页右上角的 **☆ 收藏 / ★ 已收藏** 按钮已替换为 **⚙ 设置** 按钮（`140 × 88`，圆角 20，与工具栏同款描边）。

原收藏能力没有丢，收敛进设置面板：

- **收藏当前页面** 开关 → 切换即写入收藏，并弹出「已添加到收藏」提示（复刻原 08 页的 toast 反馈）
- 首页收藏提示文案相应改为「浏览网页时在右上角「设置」里收藏……」
- 页脚遥控提示改为「右上角设置可收藏」，与真实入口一致

设置面板还包含：阅读字号三档（标准 / 大 / 特大，实时作用于网页正文）、清空浏览历史、返回主页、版本信息。

## 可交互清单

**首页**
- 快捷入口 / 浏览历史 双向切换；收藏卡片点击进入搜索结果
- 历史条目点击按类型分流：文章类进文章页，搜索类进结果页
- 清空历史 → 二次确认 → 空态（条数与文案联动），空态可一键返回快捷入口
- 点击搜索框进入键盘，点击麦克风进入语音

**键盘**
- 拼音逐字母上屏（qiu→秋、ji→季…），无歧义前缀自动待定
- 候选词点击上屏、空格提交首选词、删除退格
- 中 / 英切换、符号键盘切换（4 行符号位）
- 确认搜索 → 结果页，携带搜索词

**语音**
- 动态声波 + 麦克风双层呼吸环
- 聆听中 → 完成搜索 / 取消 / 切换键盘
- 未听清态 → 重试麦克风 / 取消

**网页**
- 返回主页、刷新（图标旋转 + 轻提示）
- 结果条目点击进入文章页；文章页字号随设置实时变化
- 右上角设置：收藏开关、字号三档、清空历史、返回主页

**通用**
- 舞台 1920×1080 自动等比缩放，适配任意窗口
- 全部交互可用鼠标点按，触摸屏可用
