# 灵犀浏览器 · 高保真可交互 Demo

灵犀屏（1920 × 1080）家庭浏览器的交互原型。按 Figma 设计稿 1:1 还原，单文件 HTML，无依赖、无构建，打开即用。

### 右上角：星标收藏 + 设置

网页浏览页右上角有两个独立按钮，互不嵌套：

| 按钮 | 尺寸 | 交互（与上一版保持一致） |
|---|---|---|
| ☆ 星标 | 88 × 88，圆角 20 | 点击**直接**切换收藏：空心 → 金色实心（`#FFB020`），toast「已收藏到「我的收藏」」／「已取消收藏」 |
| ⚙ 设置 | 140 × 88，圆角 20 | 点击进入**全屏设置页**，返回键 / × 回到进入前的页面 |

打开网页时的收藏初值也按来源区分：点首页收藏卡片进入 → 已收藏；搜索、历史、结果列表进入 → 未收藏。

### 网页加载进度

每次进入或切换网页（首页卡片、历史条目、搜索结果、文章、刷新）都会走一次约 1.4 秒的加载过程，三处同步反馈：

| 位置 | 表现 |
|---|---|
| 工具栏下方 | 6px 进度条，青色渐变 `#3FA9E0 → #8CEBFF`，带外发光，宽度随进度实时增长 |
| 地址栏右侧 | 百分比数字「74%」，加载结束自动隐藏 |
| 地址栏刷新图标 | 加载期间持续旋转 |

页面主体在加载期间显示**骨架屏**（浅灰流光块），结果页与文章页各有一套版式，与真实版面同位置、同尺寸；加载完成后整体替换为真实内容，进度条冲到 100% 后停留 260ms 再淡出。遥控提示同步显示「页面加载中 74% · 请稍候」。

加载过程中进入设置页会自动终止加载，返回后直接展示已加载内容。

### 设置页（全屏独立页面）

不是侧滑面板，而是铺满 1920 × 1080 的独立页面，交互与上一版一致：顶部返回箭头回来源页，右上 × 关闭，底部遥控提示同步切换。

设置页只保留三项功能，一屏可读完：

| 分组 | 设置项 | 交互 |
|---|---|---|
| 显示与阅读 | 阅读字号 | 分段控件三档（标准 / 大 / 特大），实时作用于网页正文与列表；副文案跟随档位变化 |
| 浏览数据 | 浏览历史 | 副文案显示「本机共 N 条记录」；「清空」→ 弹确认框 → 确认后**留在设置页**、条数归零 |
| 家庭守护 | 儿童模式 | 开关；开启后副文案变「已开启 · 仅展示适宜全家浏览的内容」并 toast 提示 |

### 设置页三项功能（v1.1）

- **字号**：三档分段控件，不只是标签变化，网页正文与结果列表字号同步缩放（`--ts` 1 / 1.12 / 1.24）
- **历史记录**：展示真实条数，清空需二次确认，清空后停在设置页不跳转
- **儿童模式**：开关态 + 文案 + toast 三重反馈

收藏能力不在设置页 —— 收藏是右上角星标的直接操作，与上一版一致。

## 可交互清单

**首页**
- 快捷入口 / 浏览历史 双向切换；收藏卡片点击进入搜索结果
- 历史条目点击按类型分流：文章类进文章页，搜索类进结果页
- 清空历史 → 二次确认 → 空态（条数与文案联动），空态可一键返回快捷入口
- 点击搜索框进入键盘，点击麦克风进入语音

**键盘**
- 拼音逐字母上屏（qiu→秋、ji→季…），无歧义前缀自动待定
- 候选词点击上屏、空格提交首选词、删除退格
- 中 / 英切换、符号键盘切换（4 行符号位）
- 确认搜索 → 结果页，携带搜索词

**语音**
- 动态声波 + 麦克风双层呼吸环
- 聆听中 → 完成搜索 / 取消 / 切换键盘
- 未听清态 → 重试麦克风 / 取消

**网页**
- 加载进度：顶部进度条 + 地址栏百分比 + 刷新图标旋转 + 骨架屏（结果页 / 文章页两套版式）
- 返回主页、刷新（重新走一遍加载进度）
- 结果条目点击进入文章页；文章页字号随设置实时变化
- 右上角星标：点击直接收藏 / 取消，金色点亮 + toast（与上一版一致）
- 右上角设置：进入全屏设置页，三项功能 —— 字号三档、浏览历史（清空）、儿童模式

**通用**
- 舞台 1920×1080 自动等比缩放，适配任意窗口
- 全部交互可用鼠标点按，触摸屏可用
