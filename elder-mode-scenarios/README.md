# 长辈模式方案二：高频场景预置

[在线体验](https://jeneyzhang016-cyber.github.io/lingxi-browser-demo/elder-mode-scenarios/)

第一页保留六张固定卡片。第二页预置看家人（移动看家）、玩棋牌（咪咕游戏）、看视频（抖音）。卡片是推荐入口，首次点击才模拟下载和安装；完成后自动加入长辈模式并打开应用，再次点击直接打开。状态保存在当前浏览器中。支持取消下载及断网后重试。

本页面是交互原型，不会实际下载、安装或启动第三方应用。接入设备时需对接应用商店的下载、安装结果和应用启动接口。

原方案位于 ../elder-mode/，互不覆盖。
