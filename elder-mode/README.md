# 灵犀屏 · 长辈模式交互原型

[在线体验](https://jeneyzhang016-cyber.github.io/lingxi-browser-demo/elder-mode/)

单文件 HTML，无依赖，下载 index.html 后可直接在浏览器打开。

- 六张预置卡片固定展示，不支持移除或排序。
- 翻至后续页面，点击「添加应用」进入自定义应用暂存区。
- 暂存区仅管理从应用商店添加的应用，支持拖动排序和移除。
- 点击暂存区末尾的「＋」打开应用选择面板，选择后返回暂存区。
- 点击「完成」保存配置；配置保存在当前浏览器本地。
- 长按已添加的自定义卡片也可进入暂存区。

应用打开为交互演示，不连接实际应用商店或真实业务服务。
